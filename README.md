# To-do List

An object focused project. The goal was to create a to-do list application by utilizing all concepts learned about objects, function factories, IIFEs and classes. It allows the user to track their tasks easily with an indication of priority on each task. 
Additionally, users can create personal projects and store specific tasks in user-defined projects.

## Features
- Adding of new tasks and projects
- Deleting of tasks and projects
- Update status of each task
- Local Storage for persistence across sessions

## What I learnt
- Modular Javascript architecure: Seperating applicaiton logic, DOM rendering, and data persisntence into their own modules making them more maintianable.
- Factory functions and IIFE patterns: Utilized immediately invoked function expressions to encapsulate state and expose only needed function, avooiding global scope
- Classes: Task and Project classes with their own methods
